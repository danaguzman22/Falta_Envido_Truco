# Documentación del Torneo

Carpeta para almacenar documentación, imágenes y PDFs del torneo de truco.

## Estructura de carpetas

```
doc/
├── reglas/          # PDFs de las reglas del torneo
├── images/          # Imágenes de reglas, instructivos y documentación
└── recursos/        # Otros documentos y materiales
```

## Contenido esperado

### doc/reglas/
- Bases y condiciones del torneo (PDF)
- Reglamento general (PDF)
- Documentos de inscripción
- Cualquier PDF relacionado con las reglas

### doc/images/
- Capturas de pantalla de reglas
- Imágenes explicativas
- Diagramas de juego
- Fotos del torneo

### doc/recursos/
- Guías de participación
- Formatos de inscripción
- Documentos administrativos
- Otros materiales de referencia

## Notas

- Todos los archivos PDF y de documentación deben almacenarse aquí
- Mantén un registro ordenado de los documentos para fácil acceso
- Considera nombrar los archivos de manera descriptiva (ej: `reglas-truco-2026.pdf`)
